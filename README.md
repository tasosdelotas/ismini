# ismini

A local AI agent that runs on your PC. Powered by LM Studio. No cloud. No API costs. Your data stays on your machine.

## Versions

| Platform | Repo |
|----------|------|
| **Linux** | [ismini-linux](https://github.com/tasosdelotas/ismini-linux) |
| **macOS** | [ismini-macos](https://github.com/tasosdelotas/ismini-macos) *(coming soon)* |
| **Windows 10/11** | [ismini-windows](https://github.com/tasosdelotas/ismini-windows) |

## What is it?

ismini is a terminal/web chat AI agent with tools (read, write, edit, exec, web search, web fetch). It connects to a local LLM via LM Studio's OpenAI-compatible API.

- Zero dependencies (Node.js built-ins only)
- Model-agnostic — uses whatever model is loaded in LM Studio
- Binds to 127.0.0.1 only — never exposed to the network
